* Overview

Complementary Themes keeps ordinary text quiet while using two accents for
structure and state. Installation details are available in the
[[file:../README.org][project README]].

- *Bold text* preserves the default weight.
- /Italic text/ and _underlined text_ retain their original attributes.
- Inline ~code~ and =verbatim text= remain easy to distinguish.

** Palette roles

| Role      | Purpose                         | Example   |
|-----------+---------------------------------+-----------|
| Neutral   | Ordinary text and quiet UI      | Body text |
| Primary   | Declarations and reserved forms | Keywords  |
| Secondary | Names, types, and strings       | Values    |

** Emacs Lisp example

#+begin_src emacs-lisp
(defun complementary-preview-greeting (name)
  "Return a short greeting for NAME."
  (let ((message-text (format "Welcome, %s" name)))
    (message "%s" message-text)))
